# 火眼套件 CLI 集成（可选，Windows）

> 本项目不附带火眼软件；以下命令来自实测，路径请替换成你自己的安装位置。
> 通用：Electron 类程序不要用 `Start-Process` 直接启动（会静默退出），用
> `cmd /c start "" "<exe>"` 且把 `TEMP`/`TMP` 指到 ASCII 路径（如 `C:\tmp`）。

## APPAnalysis（APP 分析）

```powershell
$cli = '<Forensix>\APPAnalysis\skills\bin\thunder-app-cli.exe'
& $cli health                       # 确认 status:ok / api_version
& $cli device list --refresh        # 设备列表（真机才可脱壳）
& $cli case create --name <案名> --case-path <案件目录>
& $cli evidence add --cid <caseId> --aid <appId> --file <apk>
& $cli analysis permissions|third-party|detail --cid <caseId> --aid <appId>
& $cli source decompile --cid <caseId> --aid <appId>
& $cli unpack start --cid <caseId> --aid <appId>   # 需要 ROOT 真机
```

## DatabaseRecovery（数据库取证）

master 端口**每次启动随机**，从进程命令行取，不要写死：

```powershell
$m = Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -match 'DatabaseRecovery\\master\.exe' } | Select-Object -First 1
$port = [regex]::Match($m.CommandLine, '--port=(\d+)').Groups[1].Value
Invoke-WebRequest "http://127.0.0.1:$port/api/v1/app/options" | Select-Object StatusCode   # 200 = 已授权
```

CLI 位置：

```

<Forensix>\DatabaseRecovery\skills\database-search\database-search-cli.exe
```

## 常见坑

- `TEMP` 指向过长的用户目录会导致锁文件/安装临时文件被拒 → 设 `TEMP=C:\tmp`；
- DatabaseRecovery 卡 `Loading...` 且 `master.error.log` 出现 `Access is denied` → 关闭后把
  `%APPDATA%\DatabaseRecovery` 改名备份，再启动；
- Defender 可能把便携版里的 `sqlite.exe` 当风险软件隔离 → 需要把工具目录加入排除。
